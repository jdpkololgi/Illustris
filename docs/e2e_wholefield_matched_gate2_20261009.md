# Matched six-phase Gate 2: saved-input prerequisite blocked

## Decision

The requested matched Gate 2 could not be simulated with the fixed corrected
continuous summaries. This is **missing input, not insufficient sensitivity**.
No model was trained, no GPU was allocated, no fields were regenerated, and
ph018/019 were not opened. The earlier two-phase screen does not answer the
matched six-phase question and must not be used to stop or qualify that design.

There are two separate mismatches in the earlier screen: it used only ph012/013
and one model seed, and its parent draws were generated by the later full-cap
canvas rather than the original pair-local evaluation. Same checkpoints and
region labels do not make these the same posterior draw law.

## Why the corrected tidal summaries are missing

`e2e_cfm_conditioning_extract.py` defines the previous Gate2 corrected operator:
full-cap free-space tides of the saved exterior-completed density, plus a
trace-free local conservative-linear reconstruction correction. That correction
uses32native cells of padding plus one slope collar around the32x16x16core pair:
a98x82x82native-density patch. The saved64x48x48pair-local rectangle provides
only16native cells around each side of that core pair. The coarse `wide` array
does not determine the missing native-resolution cells or the shared full-cap
state. Upsampling it, changing padding/boundaries, using periodic patch tides,
or stitching independent pair draws would define another estimator or draw law.
None is silently substituted here.

## Amended decision requirements and work deliberately not run

The plan now matches six phases and both seeds; preserves the same13training
phases; restricts checkpoint selection to012/013; and uses the six-phase pool
for advancement with014--017 reported separately as out-of-fit, not selected
after outcomes. All pairs and both seeds stay inside their phase in resampling.
The minimum accepted pooled |R-1| improvement is10%, while powered true effects
are20% and40%, each requiring80%power; full-rule false advancement must be<=5%.
Frozen seed variation must enter the noise floor. Keep b06670e's four synthetic
laws, correlations0/.9/1 and necessary-event rejection logic.

Because the exact summary bank is missing, no synthetic fixtures were fit and
no new executable statistical binding, power run, phase bootstrap, joint-score
calibration or full-rule false-advancement experiment was performed. The noise-
floor formula, joint-score margin and selector must be bound and committed
before any future simulation. The document amendment is not an executable
binding or evidence that those requirements have passed. Both six-phase and
014--017 full-vector pooled results remain unavailable.

To proceed requires an explicit scope decision: either define and validate a
different corrected operator on the saved pair-local fields, or prepare an
approved, costed matched full-cap evaluation including both model seeds and
missing phases. The latter requires new fields and would be a new full-cap
comparison, not reconstruction of the original pair-local draws. No such work
is authorized or launched here.
